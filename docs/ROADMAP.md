- [x] 本地启动脚本与后端自动化测试。

- [ ] 实现阶段开始时确定依赖版本、初始化 Git 和项目元数据。

## 阶段 1：单上游链路（建议第 1 周）

- [ ] 初始化 FastAPI、配置校验、HTTPX 生命周期与后端依赖配置。
- [ ] 完成 PostgreSQL / Redis 开发连接、首次 Alembic 迁移和幂等 bootstrap。
- [ ] 实现虚拟 Key 校验、上游 Key 加密存储与脱敏日志。
- [ ] 实现 `/v1/models`、单上游非流式 `/v1/chat/completions` 和健康接口。
- [ ] 使用短事务记录请求开始、尝试与最终状态。
- [ ] 提供模拟上游和 curl 示例；验证无效 Key、正常响应、错误响应以及故障记录。

验收：无需真实付费 Key，能跑通一次网关请求并在数据库中定位对应记录。

## 阶段 2：路由与治理（建议第 2 周）

- [ ] 实现优先级与权重选路、不同上游切换和最多 3 次尝试。
- [ ] 实现 Redis RPM、上游并发租约及所有者检查、续租和超时回收。
- [ ] 实现共享熔断与半开探针，区分限流、不可用和上游请求错误。
- [ ] 验证 429 / 500 / 连接超时 / 4xx、Redis 中断、数据库中断和 worker 退出。
- [ ] 在至少两个 API worker 下验证共享限制，避免只测进程内状态。

验收：可用故障脚本稳定复现切换和限流；一个请求的全部尝试可追溯。

## 阶段 3：SSE 与可见性（建议第 3 周）

- [ ] 实现 SSE 增量转发、首字节前切换、流中断和客户端取消处理。
- [ ] 区分总延迟、流式首字节延迟、usage 已知 / 未知，以及请求与尝试统计。
- [ ] 实现受保护的请求查询、上游状态和总览统计接口。
- [ ] 按用户确认的结构完善 React 管理台；先实现 Overview、RequestLogs 和 Usage，只读展示真实数据。
- [ ] 验证长流续租、断连释放、中途数据库故障和未完成请求的识别。

验收：流式响应不会因代理缓冲而整段返回；客户端断开后不继续占用上游并发额度。

## 阶段 4：测试、部署与发布材料（建议第 4 周）

- [ ] 使用真实 PostgreSQL / Redis 做集成测试，模拟上游用 respx 或可控服务。
- [ ] 完成 Docker Compose、Nginx SSE 配置、迁移和就绪检查。
- [ ] 增加 Ruff、pytest、前端构建和 Compose 冒烟检查的 CI 流程。
- [ ] 完成 Locust 场景，记录机器配置、并发、P95 延迟、错误率与结果口径。
- [ ] 补齐快速启动、截图、架构图、已知限制、开源许可与贡献说明。

验收：新环境按 README 启动，能复现成功调用、上游故障切换和共享限流。压测结果可复查，不使用虚构指标。

- [ ] 完成 Key 创建后仅展示一次、撤销、配置校验和管理员审计。
